# Supabase untuk formulir masukan

1. Buat proyek di supabase.com (akun dan proyek dibuat oleh pemilik; tidak ada kunci di repo ini).
2. SQL editor: tempel isi `feedback.sql`, jalankan.
3. Project Settings > API: salin **Project URL** dan **publishable key** (bukan secret key, bukan service_role) ke `../config.js`.
4. Uji: kirim satu masukan dari halaman Masukan, lalu lihat barisnya di Table editor.
5. Bila tidak ada orang yang mengirim, proyek gratis dijeda setelah 1 minggu tanpa aktivitas. Pulihkan dari dashboard.
